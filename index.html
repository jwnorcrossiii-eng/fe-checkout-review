How the test works

  • The new layout lives on a copy of each offer, so the current page is never edited for the test.
  • A small piece of code on the current page sends a random half of visitors to the copy. The ads themselves don't change.
  • Sales show up separately for each version in Kajabi, so the comparison is clean.
  • A first check after a week, and a decision after 3 to 4 weeks. If the new layout doesn't clearly sell more per visitor, it gets switched off.
